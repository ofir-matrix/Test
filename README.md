# Workspace Overview

This workspace hosts the `romi-calculator` React application. Use the commands below from the repo root:

- `cd romi-calculator && npm install` – install dependencies
- `cd romi-calculator && npm run dev` – launch the static ROMI calculator locally
- `cd romi-calculator && npm run build` – produce the production bundle
- `cd romi-calculator && npm run test` – execute the Vitest coverage-focused suite (tests live under `romi-calculator/tests`)
